What is Kiali's, and what it becomes here

  • Graph type (service, app, workload) becomes View, one per layer of the architecture. Model is the domain model as declared: the CRs and what references what. Components is one node per component the repository builds, adapters, gateway, manager, runtime images, the two sidecars, housekeeping, plus the systems outside: the model, the MCP servers, the repository, Alertmanager, Home Assistant, the Telegram API, the Kubernetes API. A runtime image running in three pods is one node with a count of three. No owner boxes. Infrastructure is what runs: every pod, and the systems outside the cluster. Nothing from the model is a node there. The pipeline and conversation a pod serves are attributes in its panel, and the only box is the cluster node it runs on. A conversation pod is one icon until you expand it into its agent container and two sidecars.
  • Detail folds the Model view, and only that one: Routes only is one node per pipeline with its profile, runtime and capabilities inside it, Kiali's service graph. Each further level unfolds more of the model.
  • Namespace selector becomes Pipelines: a route is a pipeline and everything it reaches, and the graph shows the selected routes only.
  • Box by namespace / app becomes Box by bundle / route on the model: ownership, never kind. Shared substrate stays unboxed, like a shared service. No rule positions a box.
  • Layouts are Kiali's three. Concentric draws a hub as a hub, the manager at the centre and rings by distance. Cola is WebCola, the constraint layout behind Kiali's option of that name, groups kept together. Dagre ranks, for the model read as a flow. Each view remembers its own.
  • Traffic animation: dots move in the direction the event travelled, red diamonds are errors, hollow rings are sent-but-unconfirmed. Speed follows the edge's rate.
  • Find / Hide: the same two expression boxes, over agent-ops facts: kind=pipeline, name~k8s, lane=ingest, !healthy, idle, rate>1, joined with and.
  • Replay: Kiali's toolbar exactly, in 10-second frames over 1 to 30 minutes, slow / medium / fast.

What Kiali does not have

  • What crossed. Click a pulse or a hop row in live, replay or conversation replay: the signal's title and labels, the input text, the work unit's tools and context handle, the run's result, the op's message and the adapter's report.
  • The conversation's own machinery is on the graph. In Instances and Components a pod is a box of three containers. The manager's work reaches the agent through context-sync, every model and tool call leaves through the egress proxy, and the context claim is written by context-sync alone. A restore is the sidecar handing the agent its context, a checkpoint is a pulse on the sidecar, each carrying its generation, file count and bytes. The volumes are shared substrate and are not drawn.
  • The harness and the model are on the graph. A runtime runs a harness, the harness calls an LLM and its MCP servers, and every turn and tool call is a hop with tokens, stop reason and duration. The manager never sees these today. They are the runtime's own report and the egress proxy's per-host counts, which is where a real implementation would take them from.
  • Replay one conversation. A request in a mesh is gone once its span is sampled away. A conversation here is a Kubernetes object with every run recorded, so its hops can be walked one by one with their real gaps.
  • Honesty counters. Hiding a class or scoping to a route never hides a failure silently. The health chips count every element, hidden or not.
  • Scope to route replaces Kiali's double-click "node graph": upstream plus downstream, never turning around through a shared hub.

Try

  • Switch View to Components, then Infrastructure. Click the same pulse in each. Back on Model, set Detail to Routes only.
  • Switch Detail to + work, click a conversation, press Replay conversation.
  • Switch Box by between bundle, route and none. Open Pipelines and keep one. Double-click a channel and step the depth in the scope chip.
  • Type !healthy into Find, or idle into Hide.
  • Press Replay, pick a speed, drag the slider. The window's rates and dots follow the frame.
