# landing-presentation Delta

The capability is retired whole. The landing page shows the generated flow
picture instead (see the `docs-site` delta), and the landing page was the
presentation's only user.

## REMOVED Requirements

### Requirement: A presentation is a list of beats the page writes

**Reason**: The landing page no longer declares a presentation. The static
flow picture states the model in one glance, and the beats restated what
`README.md`'s drawing already shows.

**Migration**: `docs/index.md` replaces its beat lists with the `readme-flow`
picture. The `.ao-presentation` component, its CSS and its script leave the
theme in the same change.

#### Scenario: The component is gone

- **WHEN** the theme's assets are searched for the presentation component
- **THEN** no `.ao-presentation` style, script or layout hook remains

### Requirement: Without scripting it is the story in order

**Reason**: Retired with the component — a picture needs no no-script
fallback beyond its alt text.

**Migration**: None. The flow picture is an ordinary themed image.

#### Scenario: Scripting is unavailable

- **WHEN** the landing page renders with no script
- **THEN** the flow picture still shows, light variant, with its alt text

### Requirement: The drawing is present from the first beat

**Reason**: Retired with the component. There are no beats.

**Migration**: None.

#### Scenario: The page opens

- **WHEN** the landing page opens
- **THEN** the whole flow picture is visible at once

### Requirement: The presentation never scrolls inside itself

**Reason**: Retired with the component.

**Migration**: None. The picture scales as any themed image does.

#### Scenario: A narrow viewport

- **WHEN** the landing page renders at phone width
- **THEN** the picture scales down without an inner scrollbar

### Requirement: A beat carries the resource text it is about

**Reason**: Retired with the component. The manifest panel keeps the one
selectable `Pipeline` example the opening owes.

**Migration**: None — the manifest panel already exists.

#### Scenario: A reader wants the YAML

- **WHEN** a reader wants the resource text the opening shows
- **THEN** the manifest panel carries it as selectable page text

### Requirement: The reader controls the presentation

**Reason**: Retired with the component. A still needs no transport, no pause
and no scrub.

**Migration**: None.

#### Scenario: The picture is clicked

- **WHEN** a reader clicks the flow picture
- **THEN** nothing plays, because nothing is animated

### Requirement: The presentation carries no burned-in text

**Reason**: Retired with the component. The flow picture is generated by
`readme-flow.py`, where its text and theming already live.

**Migration**: None.

#### Scenario: The drawing's wording changes

- **WHEN** the flow drawing's wording must change
- **THEN** `readme-flow.py` is edited and re-run, and both the README and the
  landing page pick it up

### Requirement: Reduced motion is a still the reader may start

**Reason**: Retired with the component. The page now shows a still to every
reader, so reduced motion needs no branch at all.

**Migration**: None.

#### Scenario: A reduced-motion reader opens the page

- **WHEN** a reader with reduced motion set opens the landing page
- **THEN** they see exactly what every other reader sees
