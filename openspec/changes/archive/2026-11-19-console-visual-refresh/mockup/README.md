## Console mockup

`console.html` is the clickable prototype this change was settled on.

1. Open it in a browser. It is one file with its data inlined.
2. Use the Simulate menu to play a live run, an arrival and a failure.
3. Read `design.md`, section "The prototype", for where it is and is not the target.

The data is scrubbed of identifiers. Do not paste a real install into it.
