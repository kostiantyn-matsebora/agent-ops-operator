new — /contracts/agent-profile/ (CRD reference)

AgentProfile specification

Who the agent is and how it behaves — identity, never reach. Tools, MCP servers and channels come from the Pipeline routing it, never from here.

spec, at a glance

apiVersion: agentops.dev/v1alpha1
kind: AgentProfile
metadata:
  name: k8s-engineer
spec:
  agent: k8s-engineer          # the agent definition to adopt, from .claude/agents/
  repository:                  # omit this block to run as a pure advisor, no checkout
    url: https://github.com/org/ops-agents
    ref: main
  env:                         # standard Kubernetes env vars, passed through as-is
    - name: LOG_LEVEL
      value: info
  maxTurns: 40                 # turn budget for one work unit, a runaway bound
  outputFormat: blocks         # required, no default — see Concepts for why
  prompt: prompts/first.md     # repo-relative template for the first unit
  systemPrompt: |              # inline role text, for a profile with no repository
    You are a careful Kubernetes operator…

Every field

FieldTypeReq.Meaning
agentstringThe agent definition to adopt, from .claude/agents/<agent>.md.
repositoryobjectGit repo the agent runs from. Omit it to run as a pure advisor.
env[][]EnvVarExtra environment for the agent process — standard Kubernetes env var, Kubernetes docs ↗.
maxTurnsintegerTurn budget for one work unit. A runaway bound, not a conversation budget.
outputFormatstringyesThe agent's output contract, blocks or none. No default — see why in Concepts →.
prompt / replyPromptstringRepo-relative templates for the first unit / a follow-up.
systemPromptstringInline role text, for a profile with no repository.

7 fields, 7 comments, one table — the whole kind on one screen. Today's cr-reference.md gives this same kind 34 rows, 24 of them Kubernetes' own EnvVar internals, and a 9-sentence description on outputFormat alone. A well-known Kubernetes type gets one row and a link here, never unrolled — and outputFormat's full rationale stays in Concepts, quoted there already rather than invented for this page.
