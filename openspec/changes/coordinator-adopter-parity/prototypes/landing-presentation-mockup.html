Pipeline vs Orchestrator

Same install, different shape. A Pipeline is a chain: source to agent to channel. A Coordinator is a hub: one agent that decides, branching out to whichever members the moment calls for.

Each kind draws the shape it gets in the console's own topology (hexagon trigger, cylinder channel, circle identity, diamond decision) — not a label in a uniform box. Conversation names follow the upcoming word-chain scheme (kind-word-word, numeric suffix on collision), not a random hash.
