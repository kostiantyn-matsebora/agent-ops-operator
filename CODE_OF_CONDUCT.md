# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1][covenant]**, by
reference and unmodified.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

**By reference, not copied.** A vendored copy silently forks from its upstream:
it stops receiving corrections, and a reader comparing the two cannot tell
which divergence was deliberate. The link above is the text that applies.

## In short

Everyone participating here — issues, discussions, pull requests and reviews —
is expected to behave with the respect the Covenant describes. Harassment,
personal attacks and unwelcome attention are not tolerated, and neither is
publishing someone's private information.

## Reporting

**Report to the maintainer, [@kostiantyn-matsebora][maintainer], through
GitHub.** Reports are handled privately, and the reporter's identity is not
disclosed without their agreement.

[maintainer]: https://github.com/kostiantyn-matsebora

If the report concerns the maintainer, or you would rather not go through this
project at all, GitHub's own [abuse reporting][abuse] goes to GitHub rather
than here.

[abuse]: https://github.com/contact/report-abuse

**One person enforces this**, which is worth saying plainly: there is no
committee to appeal to, and the acknowledgement target is the same as the
security policy's — within 7 days. Enforcement follows the Covenant's own
escalation ladder, from a private correction through to a permanent ban.

**A security vulnerability is not a conduct report.** That route is
[SECURITY.md](SECURITY.md), and it is private for a different reason.
